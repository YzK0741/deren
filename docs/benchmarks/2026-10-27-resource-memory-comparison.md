# 三种纹理方案：资源分配与性能对照（2026-10-27）

归属 [amnis](../amnis.md)。下文保留采集时使用的方案名称与命令，作为实测记录。

> **后续更新：** 本页的 CPU 稳态数字是 texture-source ownership 优化之前的实测值，已被
> [texture source memory](2026-10-27-texture-source-memory.md) 更新；GPU 分配与纹理策略的对照仍然有效。
> 当前初始化峰值与 consuming-import 数据以该更新页为准。

本轮配置为 `subtilis=false`、`software_raster=false`；保留 visibility-buffer 几何路径，
比较的是纹理流送策略，不能将其当作 subtilis DAG＋HZB＋amnis 的组合性能结果。

本轮使用新加的 `api_core.resources->memory_statistics()` 和
`utility::vessel::memory_statistics()` 重新采集，三种模式共用同一组二进制和着色器。

- **无纹理流送 / eager**：全量纹理预加载、常驻。几何 GPU 剔除保持开启，作为隔离纹理优化因素的基线。
- **纯 GPU / gpu**：原来的当帧 GPU 可见性反馈、同步加载和卸载整张纹理。
- **当前 / current**：GPU 反馈、低清常驻、异步加载、中间 mip / 屏幕需求控制，optional budget 512 MiB。

当前方案在此次测试中兼顾了接近预加载的帧耗时和更小的 GPU 资源分配量。
两种流送方案都比预加载多保留约 2.25 GiB 的 CPU vessel 存储；当前方案相对纯 GPU
只增加约 0.34 MiB，主要 CPU 代价来自两者共有的源纹理保留方式。

## 方法与统计口径

RTX 4060 Laptop GPU，NVIDIA 617.42，Release 动态后端，Bistro core MR，1280×720。
相机参数 `35,8,42,0,-88,0`，固定动画时间，geometry visibility buffer 开启；
shadow / TAA / SSAO / bloom / FXAA 关闭，与前两轮报告的简化渲染条件一致。
固定视角和每帧转动 2° 分别测试。

计时：每种模式、每个场景两轮，第二轮反向执行模式顺序；每次请求 360 帧，
采集器实际生成 361 个呈现边界，舍弃前 60 个，共汇总 602 个间隔。表中 P95 是两轮样本
合并后的分位数，非两个 P95 的平均。间隔是呈现边界的 wall-clock 时间，不是独立 GPU 时间。
运行期间没有并发构建、测试或其他本任务的 GPU 工作；未锁定 GPU 频率与温度，结果只代表这台机器。

内存：另跑每种模式/每个场景一次，关闭 validation；从场景准备完成的 frame 0 起，每 10 个
已呈现帧查询一次，共 37 个样本。frame 180–360 的 19 个样本取中位数作为稳态。
资源峰值由分配事件持续维护，表中取截至最后一个采样点的历史最大值，包含之前的初始化，
并非只对采样到的 current 求最大值。末尾清理/日志阶段不属于这个窗口。
普通计时运行不会查询资源统计，内存运行的帧耗时不纳入性能表。

GPU 数字采用 `device_local` 分配量，包括 buffer、image 的 VMA 分配要求和对齐。
后台 staging / descriptor / scratch 等同样计入，复用对象和 view 不重复计数。
它排除 borrowed swapchain images、驱动私有分配，并不等于任务管理器或 WDDM 的驻留量。
VMA backing blocks 单独列出。CPU 数字是共享项目 allocator 的 mimalloc usable bytes，
包含容量与舍入，不是整个进程的 RSS；本轮采样本身预留的 128 条记录也计入，各模式一致。

## 性能

单位 ms，越低越好。

| 方案 | 固定平均 | 固定 P95 | 转动平均 | 转动 P95 |
|---|---:|---:|---:|---:|
| 无纹理流送 | 20.543 | 22.785 | 20.254 | 22.282 |
| 纯 GPU | 32.025 | 33.303 | 49.333 | 112.194 |
| 当前 | 20.469 | 22.100 | 20.599 | 23.515 |

反向顺序复测的平均值：固定 eager 20.254 / 20.833，gpu 32.001 / 32.049，current
20.564 / 20.374；转动 eager 20.296 / 20.211，gpu 49.283 / 49.382，current 20.853 / 20.346。
当前方案相对纯 GPU 在转动时平均耗时减少 **58.2%**，P95 减少 **79.0%**。
相对 eager 的平均耗时差约 0.35 ms；这组结果不足以把这一小差异归因于某个具体步骤。

## GPU 分配

单位 MiB（2²⁰ B）。稳态取中位数，合计峰值是同一时刻的总量，不能由 buffer/image 的独立峰值相加。

| 场景 | 方案 | buffer 稳态 | image 稳态 | 合计稳态 | 合计峰值 | VMA device-local 预留稳态 |
|---|---|---:|---:|---:|---:|---:|
| 固定 | 无纹理流送 | 413.94 | 2678.99 | 3092.93 | 3471.08 | 3776 |
| 固定 | 纯 GPU | 413.94 | 1085.33 | 1499.27 | 1499.27 | 1984 |
| 固定 | 当前 | 414.07 | 765.88 | 1179.95 | 1414.53 | 1728 |
| 转动 | 无纹理流送 | 413.94 | 2678.99 | 3092.93 | 3471.08 | 3776 |
| 转动 | 纯 GPU | 413.94 | 1069.32 | 1483.27 | 2237.97 | 1984 |
| 转动 | 当前 | 414.07 | 761.92 | 1175.99 | 1414.53 | 1728 |

转动时，当前方案相对纯 GPU 的稳态分配减少 **20.7%**，峰值减少 **36.8%**；
相对 eager 的稳态分配减少 **62.0%**。buffer 几乎不变，主要节省来自 image。
纯 GPU 的稳态采样最大合计达到 2215.30 MiB，说明中位数掩盖了相机经过其他方向时的增长；
其历史峰值进一步达到 2237.97 MiB，VMA 预留稳态采样最大值为 2496 MiB。

当前方案在固定视角的稳态低于自身初始化峰值。固定纯 GPU 的峰值反而与固定稳态相同，
所以不能用固定视角约 5.7% 的峰值差代替转动时约 36.8% 的峰值差。
保留块会使 VMA 预留量的下降小于资源分配量的下降；本轮没有重新采集 WDDM 进程计数，
不能直接把这些数字与上一报告的 WDDM 表相减。

## CPU vessel 内存

单位 MiB，包含项目 allocator 的所有客户。

| 场景 | 方案 | 当前稳态 | 历史峰值（截至最后采样） |
|---|---|---:|---:|
| 固定 | 无纹理流送 | 5449.10 | 5459.73 |
| 固定 | 纯 GPU | 7749.39 | 7755.54 |
| 固定 | 当前 | 7749.72 | 7755.93 |
| 转动 | 无纹理流送 | 5449.13 | 5459.73 |
| 转动 | 纯 GPU | 7749.41 | 7755.54 |
| 转动 | 当前 | 7749.75 | 7755.93 |

两种流送的 CPU 稳态约 **7.57 GiB**，eager 约 **5.32 GiB**，差约 **2.25 GiB**。
代码中，纯 GPU 分支为 lazy image 复制并保留完整 `tex.data`；当前分支也为后续 mip 升级保留
完整 `entry.source`（`runtime.constructor.cppm` 的两条注册分支）。这与本轮差值一致。
因此，卸载 GPU 图像并不意味着卸载源纹理的 CPU 副本。当前方案相对纯 GPU 的增量很小，
但两者共有的源数据保留成本依然值得后续单独分析。

## 验证与复现

- 完整回归 **73/73** 通过。首次发现新增资源说明未列入 Doxyfile，补齐后完整重跑通过。
- 实际 Vulkan validation + 当前方案 + 资源采样：退出 0，reported error / VUID 数为 0。
- 18 组正式采集全部退出 0，各产生一张末帧图；采集器日志未报告后端错误。
  正式性能/内存运行关闭 validation，其结果不能替代单独 validation 运行。
- 资源样本检查 supported、整数/非负、同锁分类加和、总量与 device-local 关系、峰值下界及单调性、
  严格递增帧号和至少三个稳态帧。7 组新增无效数值/帧样例先失败后通过；现有 6 个测试方法全部通过。
- 独立只读审查发现并推动修复了无效计数未拒绝的问题；复审确认该问题已修复。
- 最终独立核对报告与 CSV / 图像 JSON，重算百分比和 CPU 差值后未发现口径或结论问题。
- 全部 19 组（含 validation）二进制与 shader 哈希一致。
