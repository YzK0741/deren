# Subtilis corrected raster and textured-scene measurement

The corrected software producer passes the planar CPU/GPU fixture, but adding software raster is a net cost on this textured Bistro test. Prefer visibility buffer + Cluster DAG + HZB for this scene; software raster remains experimental/default off. The earlier 5.22 ms / approximately 26x software-enabled headline is withdrawn as accepted evidence because it predates three raster wiring fixes.

## Method and results

The same textured compatibility asset, executable, shader bundle, camera, resolution (1280x720) and render settings were used for all configurations. Three rounds per camera/configuration, 129 timed GPU frames per round, 24 completed captures. Shadows, TAA, SSAO, bloom, FXAA and validation were disabled for performance captures. GPU and CPU-active numbers below are medians of the three reported session averages; CPU-active time is not a separately measured end-to-end presentation time. Raw rows, executable/asset hashes and image comparisons are retained in [results JSON](2026-10-23-subtilis-textured-results.json). Raw logs/configurations/images remain under `tmp/subtilis-textured-acceptance-resumed/` in the workspace.

| Configuration | Far GPU | Near GPU | Far CPU-active | Near CPU-active |
| --- | ---: | ---: | ---: | ---: |
| Visibility buffer, three options off | 25.52 ms | 22.98 ms | 5.53 ms | 5.52 ms |
| DAG | 21.18 ms | 19.84 ms | 6.48 ms | 6.27 ms |
| DAG + HZB | 10.44 ms | 5.64 ms | 7.15 ms | 6.79 ms |
| DAG + HZB + software raster | 12.12 ms | 6.32 ms | 10.39 ms | 10.00 ms |

DAG+HZB reduces GPU time by 59.1% far / 75.5% near relative to the same-build visibility baseline. Adding software increases the GPU median by 16.1% far / 12.1% near and raises CPU-active cost. Do not compare these textured measurements directly with the historical geometry-only legacy baseline to derive a new legacy speedup.

The original textured asset has TANGENT attributes unsupported by the current shared-vertex v1 converter. An explicitly named compatibility derivative removes TANGENT while preserving the original file and textures. Unknown extensions require glTF package output rather than GLB relocation. This validates that derived profile, not general tangent-profile support. The converted package is `tmp/subtilis-textured/subtilis-textured.gltf`. Logs confirm 1,873 adopted instances (1,540 shared) and 531 LOD0-only fallbacks; all-enabled captures activate the software and HZB lanes.

## Correctness evidence and its limits

Raw depth/ID readback exposed and fixed: the 2D clear guard truncating sparse dispatch; CSR frame stride omitting active-tile indices; and software mode bits being converted into post/bloom texture slots. Shader contract regression checks failed before the first two fixes and passed after them. The dedicated software endpoint now preserves the third push word.

The 24x24 planar grid fixture is generated by `scripts/measure/make_software_raster_fixture.py`, cooked with the offline converter and captured with threshold 4096 px solely to force the software path. Two validation-enabled captures at 8 and 9 frames cover both ring slots: 117,180 covered pixels, identical CPU/GPU IDs and coverage, maximum 2 ULP depth difference. GPU depth and ID hashes repeat exactly. Reproduce with `verify_software_images.py <fresh-prefix> --pixels 921600 --max-depth-ulp 8 --compare <second-prefix>`. The 8 ULP budget accommodates float arithmetic; observed difference is 2. This fixture does not prove arbitrary geometry, clipping, depth ties or all fallback cases.

For textured captures, the first far DAG+HZB/all-enabled pair is pixel-identical. Near mean RGB differences are approximately 0.0086/255, exactly matching the DAG+HZB baseline's own repeat variation; the first two near all-enabled captures are identical. Far hybrid repeats have a small variation (678 pixels, mean channel difference below 0.00031/255), so this is not a claim of global deterministic rendering. A near all-enabled screenshot was visually inspected and retains textured surfaces without obvious missing regions.

The raw oracle requires complete retained DAG source geometry and HZB disabled. Ordinary LOD0 fallback items cannot currently provide that CPU source; the diagnostic explicitly reports incomplete reference rasterization. The full-stage manifest/CSR/hardware/resolve/merge verifier remains separate and is not claimed to pass from these four raw images. Use a fresh capture prefix; output streams refuse replacement to reduce stale-data mixing.

M2 GPU cut selection and M5 streaming remain future features. The software path remains default-off while further correctness fixtures and optimization are pursued.

## Final verification

The resumed full build succeeds with 14 workers, including no-replacement diagnostic file streams. CTest passes 66/66 outside the sandbox (the boundary test creates temporary hardlinks). Both far and near all-enabled textured eight-frame captures pass with validation enabled and software activation confirmed; logs are `tmp/subtilis-validation-{far,near}/debug.log`. Raw-image verifier positive/corruption controls and the original stage-verifier self-test pass. `git diff --check` passes. No commit or push was performed.
