## Causes and changes

- Standalone converter run 40178970319: commands.cpp includes document_internal.hpp, which includes
  fastgltf, but subtilis_commands had no direct fastgltf usage requirement. Add the private target
  dependency and mark its vendored include path SYSTEM, matching subtilis_document. The local installed
  fastgltf headers had hidden the missing dependency; Debug/ASan compilation also exposed an upstream
  unused-parameter warning when those headers were treated as project code.
- Main run 40178970338: clang-tidy consumed both real and CMake synthetic module compilation entries.
  Synthetic entries referenced BMIs not built by the selected targets and did not preserve the real
  no-exceptions flags, producing missing-module and spurious exception/allocation diagnostics. The new
  driver filters synthetic records and retains one real command per source, preserving its directory,
  flags and response files. It rejects requested sources without a real command. CI retains the same
  38-source list and warnings-as-errors policy. Three Python regressions cover selection and deduplication.
- Fix remaining project diagnostics: braces, split declarations, unused parameter comments, trailing
  commas and an equivalent explicit branch replacing a nested conditional.
- Localize two clang-tidy 23 false positives: EnumCastOutOfRange on fixed-underlying stage bitmask OR,
  and readability-trailing-comma on required function-argument separators after empty {} arguments.
  The latter's automatic fix deleted required commas; the full compiler gate caught it and the commas
  were restored. NOLINT annotations name only the offending checks at the affected expressions. No
  global check exclusion or exception policy change was introduced. RHI ABI remains 55.
