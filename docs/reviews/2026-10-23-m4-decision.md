# M4 decision and fresh-review disposition (2026-10-23)

Status: **final decision - M4 software raster is EXPERIMENTAL, OPT-IN, DEFAULT-OFF and NOT ACCEPTED as a
shipping optimization.** The shipping large-scene path remains Visibility buffer + Cluster DAG + HZB.
This document records the Lead disposition of the final fresh review required by
`docs/superpowers/plans/2026-10-23-software-routing.md` Task 4. No code is changed by this decision; the
opt-in prototypes stay in the tree as documented experiments.

## Review and verdict

- Review report: [2026-10-23-software-routing-review.md](2026-10-23-software-routing-review.md) (0 Critical /
  4 Important / 12 Minor; range `4e3e25f6..d976ba13`).
- The negative-result verdict is **confirmed**, independently reproduced by the review:
  same-build Stage-3 medians hardware 9.68/5.73 ms vs GPU routing 9.48/5.31 ms with overlapping run spreads;
  CPU-active 8.85/8.66 vs 9.23/9.95 ms; cut wall still +0.16/0.30 ms. Stage-2 triangle routing: far 9.54 vs
  9.63 ms (larger spread), near 5.43 vs 5.20 ms (slower). Corrected textured matrix: DAG+HZB 10.44/5.64 ms
  vs DAG+HZB+software 12.12/6.32 ms (software adds GPU cost and CPU-active time).
- Conclusion: the software producer is no longer the GPU bottleneck (triangle pass 0.10/0.09 ms), but the
  complete hybrid frame has **no stable net win** over DAG+HZB on the measured scenes. The earlier
  5.22 ms / ~26x software-enabled headline stays withdrawn.

## Closure (2026-10-23)

The user decided to end the Subtilis phase: software raster stays optional/default-off and will **not be
optimized further**. The E1/E2 headroom + subpixel-share sweep finished enough to record an honest verdict
([report](2026-10-23-software-raster-headroom.md)): T1's no-HZB 1.54 ms upper bound overestimates the shipping
HZB-configuration budget by ~3-5x; raising subpixel share from 12% to 49% produced no stable net win
(Spearman -0.39, 5/7 paired deltas sign-flip, all spreads overlap); GPU routing removes CPU routing cost but
has no whole-frame win. E3 (Jinx static field) was stopped after source/license acquisition and a 4x4 smoke
scene; no cooked asset or measurement exists. The workstream closeout is
[Subtilis final closeout](2026-10-23-subtilis-final-closeout.md).
