# 启动 logo

用户选择独立启动窗口，暗底白色完整 deren 字标，加载完成关闭。

采用 Windows 原生无边框窗口，在配置解析后、重型加载前启动；独立消息线程保证加载时仍能重绘。首个成功呈现的场景帧关闭启动窗口，无强制等待。图片嵌入 exe，不依赖当前目录。自动截图、离屏、`--version` 跳过。启动画面失败不阻断渲染器。

考虑过主渲染窗口内绘制，但它无法覆盖 Vulkan 初始化；用户选用独立窗口。当前实现限 Windows，其他平台保持原启动方式，不新增图形依赖。窗口不抢焦点，不置于其他应用之上；渲染窗口是其 owner，避免被加载中的主窗口遮住。

实现细节由开发者决定：使用嵌入的 720 像素宽 BMP 与 GDI 绘制，封装成应用层 RAII 对象，关闭操作可重复调用。保留现有加载和帧循环。
