# Block

A one-unit cube centered on the origin, generated by `scripts/tools/make_block_asset.py` and checked in as
`block.gltf` plus `block.bin`. The helmet demo uses it to draw the volumes its collision boxes occupy: a node
whose scale matches its collision box draws exactly the volume it blocks, which is what tells a player where
the floor, the walls and the sliding door are.

Regenerate with:

```
python scripts/tools/make_block_asset.py asset/block
```
