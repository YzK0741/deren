# Gaussian flowers (NVIDIA Bouquet of Flowers)

`flowers_1.ply` is the Gaussian splat cloud used by `docs/screenshots/gaussian-viewer.jpg`:
**NVIDIA's Bouquet of Flowers**, 562,974 splats, licensed **CC BY 4.0**.

- Source: NVIDIA nvpro-samples `flowers_1.zip`
- Creator: Jean-Eudes Marvie
- License: `license_cc_by_4.0.html` (CC BY 4.0)
- Local file: `flowers_1.ply`, stored with Git LFS; run `git lfs pull` after cloning.

Attribution: "3D gaussian model of a bouquet of flowers" by Jean-Eudes Marvie / NVIDIA,
licensed under CC BY 4.0. Modifications: none; the file is the original sample cloud.

This file is a Gaussian splat asset, not a glTF model. Point `[model]`/`model =` at it
directly; the extension selects the Gaussian loader.
